# GitHub Pages 发布说明

目标：把“山医小助手”发布成可转发链接，例如：

`https://你的GitHub用户名.github.io/samfu-helper/`

## 准备文件

当前文件夹里的 `index.html` 就是完整网页，二维码已经内嵌，不需要额外图片文件。

## 发布步骤

1. 打开 GitHub：https://github.com/
2. 登录账号。
3. 点击右上角 `+`，选择 `New repository`。
4. 仓库名建议填：`samfu-helper`。
5. 选择 `Public`。
6. 创建仓库。
7. 进入仓库后，点击 `uploading an existing file` 或 `Add file` -> `Upload files`。
8. 上传本文件夹里的 `index.html`。
9. 点击 `Commit changes`。
10. 进入仓库 `Settings`。
11. 左侧找到 `Pages`。
12. `Source` 选择 `Deploy from a branch`。
13. `Branch` 选择 `main`，目录选择 `/root`。
14. 保存后等待 1-3 分钟。
15. GitHub 会生成类似：

`https://你的GitHub用户名.github.io/samfu-helper/`

## 更新页面

以后要改内容，只需要重新上传新的 `index.html` 覆盖旧文件，然后等待 GitHub Pages 自动更新。
